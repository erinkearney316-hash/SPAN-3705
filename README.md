# Enlazados al otro lado del Atlántico

Mapa interactivo en español sobre la influencia cultural de África en países centroamericanos. Selecciona una estrella para abrir la presentación de Belice, Costa Rica o Panamá; cada país incluye las secciones Música, Baile, Comida y Lengua. La ruta hacia África es una referencia regional esquemática, no un punto de origen exacto. El contenido de Comida para Belice incluye investigación académica y referencias MLA.

## Cómo abrirlo

Abre `index.html` en un navegador moderno. Se requiere conexión a internet para cargar Leaflet, los mosaicos del mapa y las tipografías. La geolocalización requiere permiso del navegador y puede necesitar un contexto seguro.

Los datos cartográficos son de OpenStreetMap y CARTO; la atribución aparece en el mapa.
